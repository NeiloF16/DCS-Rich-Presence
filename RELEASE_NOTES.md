# DCS World Rich Presence v1.0.0 — first public release

Show your DCS aircraft, map, single-player/multiplayer session, and session duration on Discord.

- Windows 10/11 x64 installer (no separate Python installation required)
- One-click setup interface with DCS Saved Games path selection
- Silent background operation; optional start with Windows
- Automatic Windows UI language selection for 12 Rich Presence languages
- High-resolution DCS Rich Presence logo using the preconfigured Discord Art Asset `dcs_logo`
- Clean uninstall; no modification of other DCS hooks or Export.lua
- No account tokens, telemetry or external account login

**Requirements:** DCS World, desktop Discord and Windows 10/11 x64. The high-resolution Discord Art Asset `dcs_logo` must remain configured on the linked Discord Developer application.

**Before installing:** close DCS World. If you used an older zip release, stop/disable its launcher first. An installer will preserve the DCS hook backup, but the older copied folder itself is not deleted.

**Note:** Unofficial community integration. Not endorsed by Eagle Dynamics or Discord. Unsigned builds may trigger Windows SmartScreen; verify the source and SHA-256 before running.
